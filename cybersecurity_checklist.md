# Basic Cybersecurity Checklist

## Password Security
- Use strong passwords.
- Enable MFA
- Do not reuse passwords

## Email Security
- Check sender addresses.
- Do not click strange links.
- Report phishing.

## Device Security
- Install Antivirus.
- Lock down devices.
- Update software.

## Network Security
- Join secure Wi-Fi network.
- No using public Wi-Fi for important things.
- Enable firewall.

## Back-up and Recovery
- Baack-up important files.
- Check back-up.
